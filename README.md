# Simple Finance Tracker

Lightweight full-stack example using Flask (Python) and a plain HTML/CSS/JS frontend.

Quick start

1. Create a virtual environment and install deps:

```bash
python -m venv venv
venv\Scripts\activate    # Windows
pip install -r requirements.txt
```

2. Run the app:

```bash
python app.py
```

3. Open http://127.0.0.1:5000 in your browser.

Notes
- Data is stored in `finance.db` (SQLite) in the project root.
- This project is intentionally minimal — feel free to extend it with editing, filtering, authentication, or export features.
